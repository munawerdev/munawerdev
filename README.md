## 🔥 Featured Open Source

### 🧱 [mason_cli](https://github.com/munawerdev/mason_cli) · [BrickHub](https://brickhub.dev)
A collection of Mason bricks that scaffold a full Flutter architecture — Clean Architecture, Bloc, dependency injection, and authentication — in a single command, following TDD principles.
- **Impact:** cuts architecture bootstrap setup time by **~70%**
- Generates features pre-bundled with standard Cubit/Bloc directory states

### 🔢 [pagination_helper](https://github.com/munawerdev/pagination_helper) · [pub.dev](https://pub.dev/packages/pagination_helper)
A lightweight, state-management-agnostic pagination utility for Dart & Flutter.
- Offset, page, and cursor-based pagination for lists and grids
- Works with Bloc, Provider, Riverpod, GetX, and plain `setState`
- Infinite scrolling with minimal boilerplate · Android & iOS
